# Modelcraft — Brand Assets

## The mark

An isometric cube drawn as an open wireframe — the three visible edges meeting at
the centre read as a 3D model in a viewport. Teal outer frame, navy interior edges.
It works because it says "model" without a single word of explanation, and it stays
legible down to 16px.

## Files

## Rules

**Do**
- Keep clear space around the logo equal to the height of the cube
- Use the SVG wherever possible — it stays sharp at any size
- Use the icon alone below about 120px wide, where the wordmark stops being readable

**Don't**
- Recolour the cube outside the palette above
- Stretch, skew or rotate it
- Put the light version on a dark background (use the dark file instead)
- Add effects — drop shadows, gradients, outlines

## Typography

The wordmark uses **Inter Bold/ExtraBold** (the site's typeface), letter-spacing `-2.2`.
If Inter isn't available, Segoe UI or Helvetica are acceptable fallbacks — but prefer
the supplied SVG files, which keep the exact spacing regardless of installed fonts.

## Note on the PNG previews

PNGs were rendered in an environment without Inter installed, so the wordmark spacing
in the PNG files is slightly looser than intended. The SVG files are correct — use
those for anything important, and re-export PNGs from them on a machine with Inter
if you need raster versions for print or email signatures.
